Aide pour Anki
  • En ligne : la formule s'insère dans ta phrase. Bloc : elle est centrée sur sa propre ligne.
  • Colle le code dans un champ de ta note. MathJax s'affiche sur ordinateur, AnkiDroid et AnkiMobile.
  • LaTeX génère des images et demande une installation LaTeX sur l'ordinateur. Garde-le pour les cas où MathJax ne suffit pas.
  • Cloze entoure la formule d'un trou {{c1::…}}. Les }} à l'intérieur sont séparés en } }, sinon Anki fermerait le trou trop tôt.
  • Éditeur HTML (Ctrl+Maj+X dans Anki) : coche cette option pour échapper <, > et &.
  • Les cases ▢ sont des champs à remplir. Suivant passe à la case suivante, Sortir quitte l'accolade ou la parenthèse en cours. Les cases restées vides sont retirées du code.
  • L'onglet Lettres donne l'alphabet latin (disposition AZERTY) et grec. Maj : un appui pour une capitale, deux pour verrouiller. Les styles droit, gras, ensemble, calligraphique et gothique s'appliquent aux lettres latines.
  • Tu peux aussi écrire du LaTeX à la main : le clavier n'est qu'un raccourci.
